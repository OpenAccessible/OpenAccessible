#OpenAccessible is an open-source accessibility toolkit that helps websites become more usable for people with visual, motor, cognitive, and reading differences. It ships as a **single-file JavaScript widget** (`script.js`) that runs entirely in the visitor's browser — no backend required on your site.

##Optionally, you can use the **OpenAccessible Cloud** platform (Laravel SaaS) to manage organization tokens, plan-based feature gates, anonymized analytics, billing, and whitelabel branding.
